# Ca Dao Semantic Search: Instruction Manual

Welcome to the Ca Dao Project. This system provides a semantic and keyword-based search engine for Vietnamese folk poetry.

## ⚠️ Important Data Policy

> [!CAUTION]
> **External Data Storage**
> All generated files, like `output.csv`, `embeddings.pkl`, and `keywords.pkl`, are stored **externally** and are not included in this repository. Do not check for these files

> [!WARNING]
> **Execution Prohibition**
> Never run any execution or testing commands in this environment (e.g., `python step3_server.py`). Running these without external data will result in errors. Do not attempt to create mock data
